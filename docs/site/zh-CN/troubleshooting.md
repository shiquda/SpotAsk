# 故障排查

## 测试连接失败

请检查设置 > **服务**中的以下内容：

1. “地址类型”和输入内容匹配。**服务根地址**用于 `https://api.openai.com/v1` 这类基础地址；**完整请求地址**用于完整的聊天接口。
2. 远程服务使用 `https`。只有 `http://localhost`、`http://127.0.0.1` 等本地服务可以使用明文 HTTP。
3. 访问密钥已保存且仍然有效。
4. 模型 ID 是服务商接受的名称。
5. 响应等待时间足够长。
6. 如果启用了代理，先点击“测试代理”确认代理可用。

## 无法发现模型

模型发现要求服务使用**服务根地址**，并且服务商提供模型列表接口。**完整请求地址**模式不支持自动发现。

如果刷新失败，先检查服务地址和访问密钥。若服务商没有模型列表接口，请手动添加模型并填写准确的模型 ID。

## 划词助手没有出现

1. 在设置 > **划词助手**中启用该功能。
2. 按提示允许“跨应用读取权限”，并检查当前状态。
3. 如果“触发方式”是“显示快捷操作”，请开启“选中文字后自动显示快捷操作”。
4. 检查“自动显示范围”。白名单模式只在所选应用中显示；黑名单模式不会在所选应用中显示。
5. 也可以手动按划词快捷键：默认是 `⌥ + ⇧ + Space`。
6. 空选区、安全输入区域，以及不向 macOS 辅助功能暴露选中文字的应用无法读取。

## 全局快捷键冲突

如果其他应用占用了同一个全局快捷键，请在设置 > **快捷键**中选择其他预设或录制新的快捷键。应用内快捷键和全局快捷键是分开设置的。

## 提示无法读取已保存的服务设置

设置 > 通用 > **清除所有本地数据**会重置异常的本地服务数据。之后需要重新添加服务和密钥。

## 需要更多信息

设置 > 通用 > **诊断**可以本地记录最近的请求和选中内容，然后使用“导出日志”生成可分享的文件。日志中不包含密钥。
