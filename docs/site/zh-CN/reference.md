# 设置与快捷键参考

## 设置分区

| 分区 | 作用 |
| --- | --- |
| 服务 | AI 服务格式、地址、访问密钥、等待时间、模型和模型发现 |
| 提示词 | 内置提示词、自定义提示词、排序、启用状态和自定义指令 |
| 划词助手 | 权限、触发方式、默认动作、自动显示、应用范围和延迟 |
| 快捷键 | 全局快捷键和 SpotAsk 窗口打开时使用的快捷键 |
| 通用 | 语言、启动行为、对话保留、代理、诊断和本地数据 |
| 外观 | 外观、字号、消息样式和阅读尺寸 |
| 关于 | 版本、项目来源和更新 |

## 默认快捷键

| 操作 | 快捷键 |
| --- | --- |
| 打开或聚焦提问窗口 | `Option + Space`（可自定义） |
| 触发划词助手 | `Option + Shift + Space` |
| 聚焦输入框 | `Cmd + L` |
| 重新生成或重试 | `Cmd + R` |
| 复制最新回答 | `Cmd + Shift + C` |
| 打开设置 | `Cmd + ,` |
| 开始新对话 | `Cmd + N` |
| 放大界面 | `Cmd + =` |
| 缩小界面 | `Cmd + -` |
| 执行前几个已启用提示词 | `Cmd + 1` 到 `Cmd + 9` |
| 发送问题 | `Return` |
| 换行 | `Shift + Return` |
| 停止生成 | `Escape` |

提示词快捷键取决于提示词顺序和启用状态。应用内快捷键可以在设置中重新指定或清除。

## 受支持的附件类型

| 类型 | 示例 |
| --- | --- |
| 图片 | PNG、JPEG、WebP、HEIC、HEIF、TIFF、GIF |
| 代码 | Swift、Python、JavaScript、TypeScript、TSX、JSX、Rust、Go、Java、C、C++、Shell |
| 文本 | TXT、Markdown、JSON、YAML、XML、CSV、TSV、LOG |

每条消息最多 8 个附件。超大图片会先做规范化处理，超大文本文件会截取前 60,000 个字符。

## 对话行为

- 在对话窗口切换模型只影响当前对话。
- “开始新对话”会回到设置中的默认模型，并清空当前草稿。
- 启用对话保留后，对话闲置一段时间会询问是继续还是开始新对话。
- Escape 行为可以在“通用”中设置：停止生成，或开始新对话。
