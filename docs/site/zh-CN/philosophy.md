# 设计理念

SpotAsk 不是"小一号的 ChatGPT"。它建立在一个不同的前提上：**不是所有的问题，都值得打开一个完整的 AI 平台**。很多日常问题——了解一个概念、翻译一段文本、总结一篇文章、润色一段回复——本身很简单，但我们通常回答它们的方式并不简单：中断手头的事情，打开浏览器，加载 AI 网站，等旗舰模型思考半天，复制结果，再切回来。

SpotAsk 想做的是另一件事：让轻量提问真的轻。这一页介绍它背后的想法，以及这些想法带来的取舍。

## 先有问题，再有工具

一个常见的经历：你有了一个问题，但在提问之前，你得先决定"去哪里问"。等你选好平台、点开页面，原来的问题可能已经忘了一半。

SpotAsk 把这个顺序倒了过来。你先把问题写下来——在一个永远离快捷键一步之遥的窗口里——然后再决定由谁来解答：

- 直接用配置好的模型流式作答（BYOK）。
- 用「外部提问」将问题一键分发至三大出口：网页端（ChatGPT、Perplexity、Grok）、桌面端应用（URI 协议）或终端中的本地 CLI Agent。
问题在它出现的那一刻就被记录下来，"去哪里问"可以慢慢决定。

## 刻意轻量

SpotAsk 刻意不做成另一个面面俱到的 AI 工作台。需要多步推理、长上下文、反复调试或多轮检索的复杂任务，更适合专门的工具——而「外部提问」就是通往这些工具的桥。

保持克制，才能保持快：

- 纯 Swift 与 AppKit 构建——安装包约 10 MB，无 Electron / Chromium 运行时。
- 常驻菜单栏，平时可以当它不存在。
- 按 `Esc` 关闭窗口即彻底结束——没有标签页、没有收件箱、没有什么会叫你回来。

目标是：关闭窗口之后，就好像 SpotAsk 从来没出现过一样，你只是带着答案回到了原来的场景。

## 键盘优先，光标不用动

SpotAsk 的绝大多数功能都不需要移动光标：呼出窗口、用预置提示词提问、复制回答、清除对话、按 `⎋` 退出。一个典型流程——比如朋友聊天时提到一个你不知道的词——从头到尾只需要按几次键盘。

所有快捷键都可以在设置里改成你顺手的组合，让软件适应你的手，而不是反过来。

## 在文字所在的地方处理它

好的问题常常来自屏幕上已有的文字。与其复制粘贴到另一个应用，SpotAsk 选择在原地工作：在 Safari、备忘录、邮件或任何应用里选中一段文字，直接在原地翻译、解释、总结、润色。回答可以替换原文、进入剪贴板，或打开成对话继续追问。

自定义提示词能把你自己的重复性文字任务，也变成同样的一步操作。

## 密钥在你手里，数据在你 Mac 上

SpotAsk 采用 BYOK 模式——使用你自己的 API 密钥。它连接你选择的 OpenAI 兼容或 Anthropic 服务，并且：

- 服务地址和访问密钥只保存在这台 Mac 的系统钥匙串里。
- 除了你配置的 API 服务商，数据不会发送给任何人。
- 没有账号系统，没有遥测后台，中间没有 SpotAsk 自己的服务器。

详见[隐私与本地数据](/zh-CN/privacy)。

## 像 Spotlight 一样原生、克制

SpotAsk 的名字来自 Spotlight（聚焦搜索）：按几个键就完成一件事的交互理念，用在"提问"这件具体的小事上。在同类工具显得过于庞大的时候，SpotAsk 追求一种原生、轻量、纯粹的体验——一个菜单栏小工具，快速做完一件小事，然后安静离开。
