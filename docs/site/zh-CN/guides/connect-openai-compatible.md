# 连接 OpenAI 兼容服务

OpenAI 以及提供 OpenAI 兼容聊天 API 的服务商，都选择 **OpenAI 兼容**格式。

## 添加服务

1. 打开设置，进入“服务”。
2. 新建服务或编辑已有服务。
3. 将“接口格式”设为 **OpenAI 兼容**。
4. 输入便于识别的名称。
5. 输入服务商提供的服务地址。
6. 选择“地址类型”。
7. 输入并保存访问密钥。
8. 添加服务商要求的模型 ID。
9. 点击“测试连接”。

## 地址示例

服务商提供基础地址时，使用**服务根地址**：

```text
https://api.openai.com/v1
```

服务商提供完整聊天接口时，使用**完整请求地址**：

```text
https://api.openai.com/v1/chat/completions
```

不同服务商可能使用不同路径，请以服务商文档为准。

## 添加模型

服务使用**服务根地址**并暴露模型列表时，可以自动更新模型列表。如果无法发现，请手动添加：

1. 在服务下选择“添加模型”。
2. 输入模型选择器中显示的“显示名称”。
3. 输入 API 要求的准确“模型 ID”。
4. 选择是否实时显示回答。
5. 准备好后选择“用于对话”。

## 配置完成后

关闭设置，按 `⌥ + Space` 提问。如果连接测试通过但提问失败，请参考[故障排查](/zh-CN/troubleshooting)。
