# 代理

如果网络环境需要使用代理，请在设置 > 通用 > **代理**中配置。

## 启用并测试

1. 开启“使用代理”。
2. 选择 **HTTP** 或 **SOCKS5**。
3. 输入服务器和端口。
4. 仅在代理要求时填写用户名和密码。
5. 点击“测试代理”。

代理用于聊天请求和模型更新。“测试代理”成功表示 SpotAsk 可以通过该代理连接。

## 测试失败时

- 与网络提供方确认服务器主机名和端口。
- 确认代理支持 HTTP 或 SOCKS5。
- 确认是否需要认证。
- 如果代理只适用于某个网络，切换到其他网络时请关闭代理。

代理凭据保存在本地，不会出现在导出的诊断日志中。
