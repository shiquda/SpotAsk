# 外部提问

外部提问让你始终在统一的快捷小窗中敲下问题，再随时跳转至专属 AI 平台深入探讨。SpotAsk 负责全局即时捕获，具体解答交由你选定的工具完成。

## 向其他 AI 提问

外部提问按钮位于新对话窗口提示词预设的下方，也可通过 `@` 命令面板或输入框预设菜单触发：

- **输入框为空时**：点击外部提问按钮、按下对应快捷键（如 <kbd>⌘ + 5</kbd>），或在 `@` 命令面板中选择，会在输入框左上方挂载待发送的目标标签。输入问题后按 <kbd>↩</kbd> 发送；此时问题才真正发出，唤起成功后提问窗口会关闭。点击标签上的 `×`、按 <kbd>Esc</kbd> 或清空输入可取消选择。
- **输入框已有内容时**：点击外部提问按钮、按下快捷键或从菜单中点选，会立即将当前问题发送到目标平台并关闭提问窗口。若目标无法打开，窗口会保留，问题与报错都留在界面上，可直接再次发送。
- **在已有对话中**：点击输入框左下角的预设 Popover 菜单按钮，也可以在列表中选择已启用的外部提问目标。
- **在其他平台重试某条回答**：在回答的模型选单中选择外部提问目标，会用该回答对应的问题去其他平台提问，并保持提问窗口打开，方便左右对照回答。

外部提问不消耗你配置的 AI 服务额度，提问内容也不会写入本地对话历史。

## 动作类型

每个外部提问条目属于三种动作类型之一。

**网页提问**：在浏览器中打开一个链接，问题自动填到链接里 `{query}` 占位符的位置：

| 名称 | 链接 |
| --- | --- |
| 问 ChatGPT | `https://chatgpt.com/?q={query}` |
| 问 Grok | `https://grok.com/?q={query}` |
| 问 Perplexity | `https://www.perplexity.ai/search?q={query}` |

::: tip 搭配脚本实现 ChatGPT 自动发送
ChatGPT 官方网页的默认行为是**预填**问题，需要手动点击发送。如果你希望跳转后**预填并自动发送**，可以安装油猴用户脚本：
- **[ChatGPT URL Prompt Auto Submit](https://greasyfork.org/zh-CN/scripts/592577-chatgpt-url-prompt-auto-submit)**（Greasy Fork）

安装该脚本后，通过链接携带 `?q=` 打开 ChatGPT 时，脚本会在输入框就绪后自动点击发送。
:::
**打开应用**：通过应用提供的链接格式把问题发送给 Mac 上的其他应用，例如支持 `quicknote://new?text={query}` 的笔记应用。

**终端命令**：在终端中运行一条命令，并把问题填进去，例如：

```text
omp {query}
```

## 添加自己的条目

1. 打开设置 > **外部提问**。
2. 点击"新建"。
3. 填写名称，选择动作类型，并在链接或命令中用 `{query}` 标出问题的位置。
4. 保存。有可匹配的品牌图标时会自动选用。

在同一个设置页可以对条目排序、停用、编辑或删除。内置条目和自己添加的条目使用同一套编辑与删除按钮。删除前会要求确认，且无法撤销。停用的条目保留在列表里，但不再出现在提问窗口中。

## 智能路由

如果你希望在未手动指定外部目标时由决策模型推荐去向，可以在外部提问列表之后的**智能路由**章节中开启**启用自动路由**。

![智能路由内联确认与 Tab 快速切换渠道](/images/spotask-decision-routing-zh.png)

- **System One / Jev 协议**：服务地址和模型合成一个入口，默认填写 TypeSafe 官方地址（`https://api.typesafe.ai`，模型 `jev-1.13.0`）。可以把地址改成其他兼容的 System One 服务，访问密钥只发给该地址。智能路由只对候选去向做结构化选择，不会改动现有的生成式对话服务配置。其他决策接口尚未接入。
- **渠道路由说明**：编辑任意条目即可同时修改链接或命令、渠道用途、适用场景，以及是否开启“每次自动路由需确认”。用途和场景留空时，仍会把渠道名称交给决策模型判断。
- **内联确认与置信度**：默认每次自动路由都会在输入框上方弹出轻量确认卡片（按 <kbd>↩</kbd> 继续发送、按 <kbd>Tab</kbd> 换个渠道、按 <kbd>Esc</kbd> 取消并保留原问题）。渠道列表里按 <kbd>Tab</kbd> 切换选中项，按 <kbd>↩</kbd> 发送。切换为阈值模式后，仅置信度严格高于阈值时才会自动放行；置信度仅代表选项分布确定性，不代表回答准确率。
- **超时与手动优先**：默认等待上限为 2 秒，可在 0.5 到 5 秒之间按 0.1 秒调整。超时后可手动选择渠道或直接在 SpotAsk 内回答。手动点选外部提问目标，或消息带有附件时，都会跳过决策模型。
- **设置页测试提问**：可在设置页输入示例问题，直接查看推荐渠道、置信度与放行结果，不会实际打开任何外部应用或网页。

![智能路由设置与实时测试路由](/images/spotask-decision-routing-settings.png)

## 快捷键

已启用条目的应用内快捷键接在提示词之后：四个内置提示词都启用时，前两个外部提问条目默认是 <kbd>⌘ + 5</kbd> 和 <kbd>⌘ + 6</kbd>。可在设置 > **快捷键**中重新指定或清除。

## 关闭功能

设置 > **外部提问**有一个总开关。关闭后按钮和快捷键都会隐藏，你的条目会保留。

外部提问条目包含在配置备份中；恢复没有该条目的旧备份也可以正常使用。

## 常见问题

**为什么没有内置 Claude 和 Gemini？** 只有能通过链接直接打开并回答问题的服务才会内置。Claude 打开后只是预填了问题，需要你手动发送；Gemini 的链接则不支持携带问题。你仍然可以把 Claude 添加为自定义条目，跳转后自己按发送。

**我的问题会发到哪里？** 手动选择外部提问时，问题只会发往你选定的目标。开启可选的智能路由且未手动指定渠道时，问题文本与候选渠道说明会先发送至你配置的 System One 决策地址以判断去向。
