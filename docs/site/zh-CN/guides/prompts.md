# 提示词

提示词把一个提问变成可复用的工作流。SpotAsk 内置四组提示词：**翻译**、**解释**、**总结**和**润色**。

## 使用提示词

在提问窗口发送前选择提示词：

- 输入框已有内容时，选择提示词会直接发送。
- 输入框为空时，先选择提示词，输入问题，再按 `↩`。

## 创建自定义提示词

1. 打开设置 > **提示词**。
2. 点击“新建”。
3. 给提示词一个清晰的名称，例如“改写邮件”。
4. 编写“内容”，说明模型应如何处理提供的文字。
5. 保存。

自定义提示词会和内置提示词显示在同一个选择器中。使用上移和下移按钮调整顺序。

## 启用和停用提示词

关闭不需要看到的提示词。停用后，它不会出现在提问窗口、快捷键或系统快捷指令中。

## 提示词快捷键

默认情况下，前几个已启用提示词对应 `⌘ + 1` 到 `⌘ + 9`。提示词顺序变化会改变对应关系，也可以在设置 > **快捷键**中重新指定或清除。

## 自定义指令

设置 > **提示词**中还有“自定义指令”。它是作用于提问的系统级指令，适合设定统一的语气、输出格式或工作方式。

## 划词默认动作

当划词助手使用“直接执行默认动作”时，默认使用第一个已启用提示词，除非你在设置 > **划词助手**中指定了其他提示词。
