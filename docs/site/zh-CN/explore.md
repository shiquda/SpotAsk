# 探索 SpotAsk

把这一页当作 SpotAsk 的能力地图。从你想完成的任务出发，快速找到对应的工作流与配置。

## 全局极速提问

按全局快捷键（默认 <kbd>⌥ + Space</kbd>）在任意应用中随时呼出专注提问小窗；输入问题、获取流式解答，按 <kbd>Esc</kbd> 立即关闭退出。

- [快速开始](/zh-CN/getting-started)

## 划词就近处理

在 Safari、备忘录、Xcode 等任意应用中选中文本，浮动操作条就近浮现。可快速翻译、解释、总结、润色，或一键填入输入框追问。

- [划词助手指南](/zh-CN/guides/selection-assistant)

## 外部提问与多向路由

将问题一键直派至 ChatGPT、Perplexity 等网页平台、本地终端 CLI Agent 或桌面应用，不消耗 API 额度，不留多余历史。

- [外部提问指南](/zh-CN/guides/external-ask)
## 多服务与模型自由切换

支持配置多个 AI 服务商与模型。你可以在设置中配置全局默认模型，也可以直接在提问窗口内快速为当前对话切换模型。

- [服务与模型指南](/zh-CN/guides/providers-and-models)

## 多模态：图片与文件附件

直接粘贴截图，或拖入图片、文本与代码文件。当前会话中的后续追问会自动保留附件上下文。

- [图片与文件指南](/zh-CN/guides/attachments)

## 提示词预设与模板复用

内置翻译、解释、总结、润色等高频模板，支持创建自定义提示词，并可通过全局系统指令统一输出风格。

- [提示词指南](/zh-CN/guides/prompts)

## macOS 原生深度集成

支持通过 Spotlight、Siri、系统快捷指令或 `spotask://` 链接唤起提问、开始新对话或执行特定提示词。

- [Spotlight、Siri 与快捷指令指南](/zh-CN/guides/macos-integration)

## 个性化外观与行为

自由调整全局快捷键、窗口尺寸、字体大小、浅色/深色外观、气泡样式与会话保留策略。

- [外观与行为指南](/zh-CN/guides/appearance)
- [设置与快捷键参考](/zh-CN/reference)

## 高级网络与连接配置

支持自定义模型端点、本地模型、网络代理、服务根地址与完整路径切换以及模型自动拉取。

- [服务根地址与完整请求地址](/zh-CN/guides/service-addresses)
- [代理指南](/zh-CN/guides/proxy)
