# Appearance & Behavior

Settings > **Appearance** controls how SpotAsk looks. Settings > **General** controls how it behaves.

## Appearance

| Setting | What it does |
| --- | --- |
| Appearance | Use System, Light, or Dark |
| Font Size | Small, Standard, or Large reading size |
| Message Style | Standard or Conversation bubbles |

Reading changes apply the next time the question window opens. You can also zoom the interface with the configured zoom shortcuts.

## Language

Settings > General > **Language** changes the app interface. Use **Automatic (System Language)** to follow macOS. SpotAsk supports 8 interface languages.

## Launch and window behavior

- **Launch at login** starts SpotAsk when you sign in to your Mac.
- **Launch silently** keeps the window hidden at startup.
- **Keep window on top** keeps the question window above other windows.
- **Clear input when closing the window** removes the draft when the window closes.

## Conversation behavior

- **Restore recent conversation** loads the last retained conversation when SpotAsk starts.
- **Conversation history limit** controls how many recent conversations or messages are kept.
- **Confirm before starting a new conversation** asks before clearing the current conversation.
- **Press Esc to start a new conversation** changes Escape behavior.

## Configuration, diagnostics, and local data

Use **Configuration Backup** to export and import settings without moving keys by default. Use **Diagnostics** for troubleshooting. Use **Clear All Local Data** to remove keys, settings, and saved conversations.
