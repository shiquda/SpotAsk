# Prompts

Prompts turn one question into a repeatable workflow. SpotAsk includes four built-in prompts: **Translate**, **Explain**, **Summarize**, and **Polish**.

## Use a prompt

In the question window, choose a prompt before sending:

- With content in the input, selecting a prompt sends it immediately.
- With an empty input, select a prompt, enter your question, then press `↩`.

## Create a custom prompt

1. Open Settings > **Prompts**.
2. Select **New**.
3. Give the prompt a clear **Name**, such as "Rewrite an email".
4. Write the **Content** that tells the model what to do with the provided text.
5. Save it.

Custom prompts appear in the same picker as built-in prompts. Use the up and down buttons to control their order.

## Enable and disable prompts

Turn off prompts you do not want to see. Disabled prompts are not available in the question window, keyboard shortcuts, or system shortcuts.

## Prompt shortcuts

The first enabled prompts get `⌘ + 1` through `⌘ + 9` by default. Prompt order changes the assignment. You can reassign or clear prompt shortcuts in Settings > **Shortcuts**.

## Custom instructions

Settings > **Prompts** also has **Custom Instructions**. This is a system-level instruction applied to your questions. Use it for a consistent tone, output format, or working style.

## Selection default action

When the Selection Assistant uses **Run default action**, the default is the first enabled prompt unless you choose a different one in Settings > **Selection Assistant**.
